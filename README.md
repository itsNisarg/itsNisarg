## ⟡ About

I'm interested in building intelligent systems at the intersection of **artificial intelligence, distributed systems, data, and research**.

My current focus is on **agentic AI**, particularly how autonomous systems can reason, coordinate, use tools, and operate reliably in real-world environments.

Beyond engineering, I'm interested in the deeper questions behind intelligent systems — **learning, decision-making, representation, and cognition**.

```text
current orbit
├─ agentic systems & LLM orchestration

├─ distributed data systems
├─ cloud-native architectures
└─ neuroscience & decision science
```
